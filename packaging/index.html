🐹 hamster

Freundliche Shell im Stil von fish: zeigt klar, wo der Fehler ist, und vervollständigt, was du tippst.

Installieren (Ubuntu & Debian)

curl -fsSL https://noi922.github.io/Linux-plugin/setup.sh | sudo sh

Ohne curl: wget -qO- https://noi922.github.io/Linux-plugin/setup.sh | sudo sh

Danach installierst und aktualisierst du hamster ganz normal mit apt:

sudo apt install hamster
sudo apt update && sudo apt upgrade
